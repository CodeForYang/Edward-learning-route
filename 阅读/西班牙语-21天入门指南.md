## 1️⃣ 搭建学习阶梯

### Lv1 入门层：建立语音和自信

**平时要做什么：**
- 掌握西班牙语的 27 个字母和发音规则（**西语发音极其规律，比英语简单 10 倍**——看到就能读）
- 学会打招呼、自我介绍、告别
- 掌握 0-100 的数字和基本颜色

**核心内容：**

```
发音规则亮点：
- 5 个元音永远发同一个音：a [a], e [e], i [i], o [o], u [u]
  → 英语元音有 20 种发音，西语只有 5 种，每个元音只有一种读法！
- 辅音基本和英语一样，只有几个例外：
  - ll → 发 [j]（类似中文"呀"的y）
  - ñ → 发 [nj]（类似"纽约"的"纽"）
  - j → 发 [h]（类似英语 hello 的 h）
  - h → **永远不发音**（hotel 读作"otel"）
  - r → 舌尖颤动，拉丁人的标志
  - rr → 多颤，练好这个就赢了一半

重音规则（背下来，以后100%的单词都能正确读）：
1. 以 n/s/元音结尾 → 重音在倒数第二个音节
  例：casa (CA-sa), hablan (HA-blan)
2. 以其他辅音结尾 → 重音在最后一个音节
  例：ciudad (ciu-DAD), comer (co-MER)
3. 有重音符号的 → 重音就在标符号的地方
  例：teléfono (te-LE-fo-no), música (MU-si-ca)
```

**✅ 对你的偷懒技巧（利用英语底子）：**
```
英西同源词——以下单词几乎和英语拼写一样，意思也一样：

英语           西班牙语
animal     →   animal
hospital   →   hospital
hotel      →   hotel
restaurant →   restaurante
importante →   importante
problema   →   problema
chocolate  →   chocolate

→ 你出门第一天就能读懂 300+ 个西语词，不用背
→ 这就是英语底子的最大优势！
```

**常见错误（❌）：**
- ❌ 把西班牙语的 j 发成英语的 j → 应该发 [h] 音
- ❌ 把 v 发成英语的 [v] → 西语 v 和 b 发音相同（[b]）
- ❌ 把 ll 发成英语的 [l] → 应该发 [j] 或 [ʒ]（取决于地区）
- ❌ 忽略重音符号 → 重音位置错了可能变成另一个词

**进阶标准：** 看到任何西语单词都能正确发音，能自我介绍并问候他人

### Lv2 基础层：日常会话起步

**平时要做什么：**
- 学会陈述句和一般疑问句
- 掌握主格代词（yo/tú/él/ella/usted...）和 ser/estar 两个"是"
- 掌握规则动词的现在时变位（-ar/-er/-ir）
- 学会谈论自己（名字、国籍、职业、喜好）

**核心内容：**

```
两个"是"的区别（中文没有，但英语 think/be 帮你想像）：
  ser → 本质属性（国籍、职业、长相、性格）
    Soy chino. 我是中国人。
    Es profesor. 他是老师。
  estar → 状态变化（情绪、位置、临时状况）
    Estoy bien. 我很好。
    Está en Madrid. 他在马德里。

最常用的规则动词变位（适用于 80% 的动词）：
  hablar (说)       comer (吃)        vivir (住)
  yo hablo          como              vivo
  tú hablas         comes             vives
  él/ella/usted habla come            vive
  nosotros hablamos comemos           vivimos
  ellos/ellas/uds.  hablan  comen     viven
```

**常见错误（❌）：**
- ❌ 混淆 ser 和 estar → 用错了外国人也能懂，但听起来很奇怪
- ❌ 忘记变位 → 中文/英语都没有这么系统的变位，是最大的难点
- ❌ 主语代词用太多 → 西语变位已经隐含了主语，通常不需要说 yo/tú

**进阶标准：** 能用现在时描述自己的一天，会用 20+ 个动词

### Lv3 进阶层：流畅的日常对话

**平时要做什么：**
- 掌握最常用的 10 个不规则动词（tener, ir, hacer, poder, querer, decir, ver, dar, saber, poner）
- **高频不规则动词变化对照**：

```
          tener(有)  ir(去)    hacer(做)   poder(能)
yo        tengo     voy       hago       puedo
tú        tienes    vas       haces      puedes
él/ella   tiene     va        hace       puede
nosotros  tenemos   vamos     hacemos    podemos
ellos     tienen    van       hacen      pueden
```

- 学会表达时间、日期、天气
- 学会用 gustar 表达喜好（你的最爱——"我喜欢听歌"）
  - Me gusta + 名词/动词原形 → Me gusta la música. / Me gusta cantar.
  - Me gustan + 复数名词 → Me gustan las películas.
- 学会在餐厅点餐、购物、问路
- 学会用 ir a + 动词原形 表示将来（最简单的将来时）

**常见错误（❌）：**
- ❌ gustar 的用法和中文/英语都不同 → 它意思是"使我喜欢"，主语是喜欢的东西，不是人
- ❌ 混淆 por 和 para → 两个都表示"为了"，但用法不同
- ❌ 形容词放在名词前面 → 西语形容词通常放在名词后面（coche rojo 红车）

**进阶标准：** 能在餐厅点餐、问路、简单描述自己的喜好

---

### Lv4 巩固层：应付常见场景

**平时要做什么：**
- 学会过去时（简单过去时）——讲述发生过的事情
- 学会表达频率（siempre 总是、a veces 有时、nunca 从不）
- 掌握必备高频介词和连接词（y, pero, porque, con, sin, para, por）
- 掌握最常用的 50 个高频动词

**常见错误（❌）：**
- ❌ 过去时变位记不住 → 先掌握最常见的不规则过去时（fui, tuve, hice, pude, quise）
- ❌ porque 和 por qué 混淆 → porque (因为，一个词不用重音), por qué (为什么，两个词有重音)
- ❌ 把英语的 false friends（假朋友）直接搬到西语

**⚠️ 英西假朋友（False Friends）清单：**
```
英语词     你以为的意思     实际意思
embarrassed → 尴尬的     ≠  embarazada = 怀孕了
sensible   → 明智的      ≠  sensible = 敏感的
constipado → 便秘的      ≠  constipado = 感冒了
actualmente → 实际上     ≠  actualmente = 当前/现在
librería   → 图书馆      ≠  librería = 书店（图书馆是 biblioteca）
 éxito      → 退出        ≠  éxito = 成功
```

**进阶标准：** 能用简单过去时讲述过去一天的经历，能用手机查词完成基本交流

---

### Lv5 应用层：独立日常沟通

**平时要做什么：**
- 综合运用所有时态（现在时 + 简单过去时 + ir a 将来）
- 听懂慢速西语对话
- 能接打电话的基本用语
- 能表达意见、感受、建议（Creo que... / Pienso que... / ¿Qué te parece...?）
- 能用西班牙语进行约 3 分钟的对话

**进阶标准：** 你能自信地和西语母语者完成一次完整的日常对话——聊聊你自己、工作、兴趣，顺便问问他的情况。可能还有语法错误，但对方完全能听懂你的意思。

---

> **一句话总结**：21 天让你从 0 到能在西语国家生存交流，靠的不是背完所有语法，而是大胆开口 + 用你的英语底子 + 听歌看剧无痛输入。

| **第 10 天** | **时间与日期** | ¿Qué hora es?、星期、月份、今天/明天/昨天 | Duolingo + 练习：现在几点？你的生日是哪天？ | 星期几为什么前不加 el？ |

| **第 14 天** | **不规则动词实战** | 10 个最常用不规则动词（tener, ir, hacer, poder, querer, venir, decir, ver, dar, saber） | 用每个动词造一个句子 | Voy al supermercado 的 voy 是什么动词？ |
| **第 15 天** | **天气与季节** | ¿Qué tiempo hace?、天气词汇、四季、感叹句 | 🎵 **听歌日**：推荐 **La Camisa Negra**（Juanes）+ 描述今天的天气 | Llueve mucho 中的 ll 怎么发音？ |
| **第 16 天** | **过去时入门（上）** | 规则动词的简单过去时变位、ar 类 | 写昨天做了什么（ayer fui/fui a/comí/bebí） | ¿Comiste pizza ayer? 怎么回答？ |
| **第 17 天** | **过去时入门（下）** | 最常用的不规则过去时（fui, tuve, hice, pude）+ er/ir 类 | 组合句：Ayer fui al cine y vi una película... | fui 既是 ir 还是 ser？ |
| **第 18 天** | **ir a 将来与计划** | Voy a + 动词、计划表达、明天/下周 | 写你的周末计划 | Voy a comer 和 Como 有什么区别？ |
| **第 19 天** | **综合场景对话** | 模拟完整对话：自我介绍 + 工作 + 爱好 + 周末计划 | 🎬 **看剧日**：看一集西语剧（推荐 Extra 或 Destinos） | 能做一段 2 分钟的自我介绍吗？ |
| **第 20 天** | **打电话与求助** | 电话用语、¿Podría ayudarme?、紧急情况、预约 | 角色扮演：订酒店、预约餐厅 | 接电话怎么先说？ |
| **第 21 天** | **总复习与模拟对话** | 回顾21天所有核心句型和词汇，自选场景模拟对话 | 找语伴或对着镜子做 5 分钟连续西语独白 | 从自我介绍到聊计划能连贯说下来吗？ |

### 学习建议

- **每天固定时间**：建议固定晚上 8:00-9:30，形成习惯
- **Duolingo 每天 20 分钟**：作为基本功积累，雷打不动
- **🎵 每周 2 天"听歌日"**：把歌词找出来看，跟唱，这是最轻松有效的方式
- **🎬 每周 1 天"看剧日"**：不开中文字幕，看画面猜意思（西语剧语速比英语慢，适合入门）
- **每 7 天休息一天总结**：复盘前一周的内容，用 AI 考官测试（见下一节）
- **利用你的英语**：遇到一个西语词，先想英语里有没有同源的——八九成有

## 3️⃣ AI 考官测试

### 交互说明

> 每次学完一个阶段（建议每周），用以下启动语找我进行口语测试。
> 我是你的 1 对 1 西语口语陪练，会模拟日常对话。

**启动示例：**
> 请开始西班牙语 Lv2 考官测试，从简单的概念题开始。

### 测试递进规则

```
Round 1 — 概念题：问核心语法/词汇
  Q: "gustar 和普通动词有什么区别？"
  Q: "ser 和 estar 的区别是什么？"

Round 2 — 操作题：按场景完成句子
  Q: "如何用西语说'我喜欢看电影'？"
  Q: "如果你在餐厅想点一份 paella，怎么说？"

Round 3 — 场景题：模拟真实对话
  Q: "我现在是马德里的出租车司机，你在上车后怎么告诉我你要去太阳门（Puerta del Sol）？"
  Q: "我们在一个聚会上，你跟我做自我介绍——开始吧"

Round 4 — 故障/应变题：在实际交流中遇到问题怎么办
  Q: "对方说得太快你听不懂，怎么办？"
  Q: "你点餐时说错了菜，要怎么纠正？"
```

### 你的专属口语启动语

- **第 7 天结束**：`"开始 Lv2 测试，我已经会自我介绍和基本问候了"`
- **第 14 天结束**：`"开始 Lv3 测试，我已经会现在时、gustar、和一些不规则动词了"`
- **第 21 天结束**：`"开始 Lv5 测试，模拟一次在马德里咖啡厅的完整对话"`

## 4️⃣ 制作速查表

### 速查表 #1：最常用日常短句

| 项目 | 内容 |
|------|------|
| **一句话** | 出门在外最需要的 10 句话，背下来直接能用 |
| **核心短句** | |
| | Hola / Buenos días / Buenas tardes / Buenas noches |
| | ¿Cómo estás? / ¿Qué tal? — 你好吗？ |
| | Muy bien, gracias. ¿Y tú? — 很好，谢谢，你呢？ |
| | Mucho gusto / Encantado — 很高兴认识你 |
| | Por favor — 请 |
| | Gracias / Muchas gracias — 谢谢/非常感谢 |
| | De nada — 不客气 |
| | Lo siento / Perdón — 对不起 |
| | No entiendo. / ¿Puedes repetir? — 我不懂/你能再说一遍吗？ |
| | ¿Hablas inglés? — 你说英语吗？ |
| **真实案例** | 在巴塞罗那街头问路：Perdón, ¿dónde está la Sagrada Familia?  |
| ❌ 常见错误 | 把 Mucho gusto 说成 Mucho gusta（gusto 是名词形式） |
| ✅ 检查清单 | [ ] 见面问候三件套下午用哪个（Buenas...）[ ] 说谢谢后等着对方回 De nada [ ] 不会说的时候用 No entiendo |

### 速查表 #2：动词变位速查

| 项目 | 内容 |
|------|------|
| **一句话** | 动词根据人称不同变化结尾，这是西语和中文最大的区别 |
| **规则动词** | -ar 类：hablar → o/as/a/amos/an |
| | -er 类：comer → o/es/e/emos/en |
| | -ir 类：vivir → o/es/e/imos/en |
| **必背不规则** | ser → soy, eres, es, somos, son |
| | ir → voy, vas, va, vamos, van |
| | tener → tengo, tienes, tiene, tenemos, tienen |
| | hacer → hago, haces, hace, hacemos, hacen |
| | poder → puedo, puedes, puede, podemos, pueden |
| | querer → quiero, quieres, quiere, queremos, quieren |
| **真实案例** | ¿Qué quieres comer? → Quiero comer paella. |
| ❌ 常见错误 | 把 yo 说成了 Yo hablo → 直接说 Hablo 就够了，yo 暗示"我"已经包含在变位里 |
| ✅ 检查清单 | [ ] 动词结尾根据人称变化了 [ ] 现在时变位还分三类 [ ] 不规则动词单独记 |

### 速查表 #3：英西同源词捡漏

| 项目 | 内容 |
|------|------|
| **一句话** | 两个词长得一样或很像，意思完全一样，英语母语者和你有同样的优势 |
| **核心概念** | -tion 结尾 → -ción（全词可以） |
| | -ty 结尾 → -dad |
| | -al 结尾 → -al（完全一样） |
| | -ist 结尾 → -ista |
| **对照表** | |
| | information → información（多一个 ó）|
| | university → universidad（-ty → -dad）|
| | national → nacional（基本一样）|
| | artist → artista（加了一个 a）|
| | important → importante（加了一个 e）|
| | different → diferente（小小变化）|
| **真实案例** | 你在机场看到 Información，立刻知道是 Information 柜台 |
| ❌ 常见错误 | 见前面的 False Friends（尴尬≠怀孕）|
| ✅ **练习** | 随便拿一段英文，把 -tion 结尾的词都换成 -ción，你就能"猜"懂一段西语了 |

## 6️⃣ 费曼循环巩固

### 用 12 岁孩子能懂的话来说

**西语 vs 中文比，最重要的区别是什么？**

> 你可以把中文动词想象成一块木头，不管谁用、什么时候用，它都一样。
> 比如"吃"——我吃、你吃、他吃、昨天吃、明天吃，都是"吃"这个字。
>
> 西语动词像一块乐高积木，**谁说**和**什么时候说**决定了它的形状：
> - Yo **como**（我吃）→ 现在时
> - Tú **comes**（你吃）→ 换了形状 → 表示"你"在吃
> - Ayer yo **comí**（昨天我吃了）→ 又换了一个形状 → 表示"昨天"
>
> 所以学西语最重要的就是记住：**动词形状是会变的**，变了你就知道谁在做、什么时候做的。

**为什么 ser 和 estar 都是"是"？**

> 想象你有两个包：
> - ser 包：放着你一辈子不会变的东西——你是中国人、你是男的、你是工程师
> - estar 包：放着今天会变的东西——你现在的心情、你在哪儿、你今天的状态
>
> 两个都是"是"，但装的东西不一样。

### 循环方法

```
Round 1: 你用自己的话说"西语的动词变位是怎么回事" → 我指出漏洞 → 你查
Round 2: 你重新说（更准确了） → 我再指出改进点
Round 3: 你再说 → 漏洞越来越少 → 你真正掌握了 ✅
```
