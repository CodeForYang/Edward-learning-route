### Day 1 · 抵达兰州

| 项目 | 内容 |
|------|------|
| **骑行** | 0km |
| **海拔/气温** | 兰州~1,520m · 8月17-30°C |
| **住宿** | **兰州中心套房假日酒店** 或 **正宁路附近亚朵** |
| | 💰 **备选（~200元）**：汉庭（中山桥张掖路步行街店）¥116起 / 速8（静宁路店）¥177起 |
| | 📍 城关区正宁路/张掖路一带，步行到正宁路夜市5分钟 |
| | 🅿️ 酒店地下车库可停摩托车，跟前台说一声安排监控车位 |
| **🍺 夜生活** | ① **河谣火塘民谣酒馆**——畅家巷208号，18:00-02:30，人均¥86。兰州最火的民谣酒馆，每晚9点歌手轮唱，氛围极好，一个人去也能跟唱。② **山河民谣酒吧**——张掖路步行街附近人民饭店地下一层，无最低消费，驻唱21:00开始，熊猫精酿¥49/罐 |
| **取车点** | 提前联系物流公司确认兰州提货点——通常在七里河区或城关区边缘物流园 |

**当天安排：**
- 中川机场落地（距市区约60km，打车50分钟）→ 物流点取摩托车
- 骑车去酒店，卸行李
- 下午去**甘肃省博物馆**——马踏飞燕真品（中国旅游标志）在这里。免费，刷身份证，预留1.5小时。周一闭馆
- 晚上去**正宁路夜市**——牛奶鸡蛋醪糟（上过《舌尖》）、烤肉、甜醅子、灰豆子。和银川怀远夜市风格不同——兰州是回族+西北风味
- 🔸 **怕正宁路人多？** 去**南关民族风味一条街**（城关区酒泉路南段），本地人自己吃的地方，品类和正宁路一样，人不挤
- 🔸 甘肃省博物馆旁边有**兰州碑林**——从甲骨文到近现代的书法刻石，山顶能俯瞰黄河。免费，几乎没人去
- ⚠️ 备用油囊先空着——到大兴安岭之前再装。兰州到东乌旗沿途加油站密集，没必要背着5L油跑几千公里

| **导航** | ① 起点：**兰州正宁路酒店** |
| | ② 途经：**临夏回族自治州**（G213/G75方向，约100km，在此吃午饭） |

| | ④ 下午：临夏 → G213 → **合作市**（约160km，2.5-3h） |
| **路面** | 全程柏油路。兰州出城后沿黄河支流河谷往南，临夏之后地貌开始变化——黄土丘陵被高山草甸取代，海拔从1,500m爬到2,900m |
| **到达时间** | 下午3-4点到合作，有充足时间休整 |
| **住宿** | **合作甘南饭店/合作国际大酒店**，200-350元 |
| | 💰 **备选（~200元）**：兴海宾馆 ¥118起 / 格林豪泰 ¥148起 / 速8 ¥148起 |
| | 📍 合作市当周街，甘南州府 |
| | 🅿️ 酒店有停车场 |
| **🍺 夜生活** | ① **酒点半音乐休闲吧**——通钦街水电花苑，合作本地年轻人常去的音乐酒吧。② 去当周街广场跳**锅庄舞**——藏族群众晚饭后自发聚集跳舞，游客加入没有人会觉得突兀。广场边有烤牦牛肉串¥3/串、甜醅子、酸奶浇蜂蜜 |

**沿途看点：**
- 临夏段：从兰州到临夏的100km，沿途清真寺密度极高——每过一个村子都有一座。临夏是回族自治州首府，**午饭推荐手抓羊肉配河州包子**，这是整个甘肃最好吃的一段
- 合作段：过了临夏之后海拔开始爬升，地貌从黄土丘陵变成高山草甸。进入合作之前经过**尕海**——G213路边的高原湖泊，8月湖水最满。不用进景区，公路边找个安全位置停车走到湖边，停留20分钟足够
- 傍晚到合作后可去**米拉日巴佛阁**拍外观——九层藏式佛阁，红白黑三色极其强烈。晚上有灯光，很出片
- 🔸 **安多合作寺**（下寺）：本地人去的寺庙，没有游客。下午3点左右有辩经，可以安静地在旁边看。从米拉日巴佛阁步行10分钟

**沿途可选绕行：**

| 绕行 | 地点 | 详细说明 |
|:--:|------|------|
| +40km | **炳灵寺石窟** | 📍 从刘家峡水库坐船进入，黄河峡谷里的石窟群。第169窟有中国最早的石窟壁画（西秦时期，比莫高窟早100多年）。坐船往返+游览约4-5小时，游客不到莫高窟的1%。**如果时间紧张可跳过，洛克之路才是明天的重头戏** |

### Day 3 · 合作 → 顺时针环线（洛克之路 + 白龙江峡谷）

```
合作 ──G316──→ 扎古录 ──洛克之路(南下)──→ 扎尕那石峰群
  ↑                                              │
  │                                              ↓
  └──── 碌曲 ←──G345(白龙江峡谷) ←──────── 迭部
        80km                           120km
```

| 项目 | 内容 |
|------|------|
| **骑行** | ~390km · 约7-8小时骑行 + 停留 |
| **海拔/气温** | 合作~2,900m（洛克之路垭口~4,000m）· 8月7-19°C |
| **导航** | ① 起点：**合作酒店**，早出发（7:00） |
| | ② 合作 → G316 → **扎古录镇**（60km，柏油路，1h） |
| | ③ 扎古录 → **洛克之路南下**（江迭公路，100km非铺装，3-4h含停留） |
| | ④ 扎尕那石峰群 → **迭部**（30km，柏油路） |
| | ⑤ 迭部 → G345白龙江峡谷 → **碌曲**（120km，2.5h） |
| | ⑥ 碌曲 → G213 → **合作酒店**（80km，1.5h） |
| **路面** | 洛克之路：碎石+泥土。其余全程柏油 |
| **住宿** | 同上（合作酒店） |

**为什么顺时针环线不走折返：**

| 时段 | 路段 | 说明 |
|------|------|------|
| **上午 8:00-12:00** | 洛克之路南下 | 8月甘南雷阵雨集中在14:00-16:00，上午骑洛克之路完美避开泥浆风险。从扎古录往南骑，扎尕那石峰群迎面从地平线上升起——和北上方向看到的完全不同 |
| **中午 12:00-13:00** | 迭部午饭 | 迭部县城吃午饭，加油 |
| **下午 13:00-16:00** | G345白龙江峡谷 → 碌曲 | 峡谷弯多但路面好。下午峡谷里云雾缭绕反而加分——雨后放晴的峡谷是一天中最美的时候 |
| **傍晚 16:00-17:30** | 碌曲 → 合作 | G213轻松收官，傍晚到合作 |

**洛克之路南下看点：**
- 从扎古录进江迭公路，爬升翻越约4,000m垭口
- **垭口之后**——石峰群迎面展开，无人机最佳起飞点
- 翻过垭口是高山草甸+白云+牦牛群——你说的"像新疆"就是这段
- Insta360挂头盔拍全程——碎石路+石峰+弯道，单独剪一集
- **不进扎尕那村**——骑到石峰群位置就走，村口门票80元+旺季排队

**G345白龙江峡谷看点：**
- 峡谷公路沿着白龙江蜿蜒，两岸藏寨+经幡+青稞田
- 和洛克之路的荒凉石峰完全不同——这里是"有人在住的峡谷"
- 下午雨后云雾从江面升起，比晴天更有层次

⚠️ 全天390km——是整趟旅程骑行强度最高的一天。洛克之路中段无手机信号，提前下载离线地图。迭部县城有中石油，务必补满。

**当天重点：永泰古城**

| 细节 | 说明 |
|------|------|
| **导航** | 搜"永泰古城"，景泰县西南27km |

| **停留** | **1-2小时**——下午到景泰后先去古城，看完日落骑回县城酒店25分钟 |

**地貌过渡日：** 早上从合作出发还是满眼绿色高山草甸，经临夏下到兰州后沿黄河北上，下午进入景泰后绿色被土黄取代。从青藏高原边缘下降到黄河沿岸的荒漠边缘——这是你整趟旅程中地貌变化最剧烈的一天。中途在临夏吃午饭（手抓羊肉），保证下午3-4点到景泰后直奔永泰古城。

## 🥇 整趟旅程 TOP 5 餐饮体验

> 这五家店不是"最好吃的五家"——是"体验感最强的五家"。排名综合考虑味道、环境、故事、和你在那一刻的心情。

| 排名 | 店名 | 位置 | 推荐菜 | 人均 | 为什么是它 |
|:--:|------|------|------|:--:|------|
| 1 | **卢布里西餐厅** | 海拉尔（总店） | 罐焖牛肉 + 红菜汤 + 俄式烤肉拼盘 | 120-180 | Day 18，你刚骑完阿尔山到海拉尔的300km林区公路。走进一个像19世纪俄国贵族餐厅的地方，木桌上铺着红格桌布，穿传统服装的服务员端着铜壶倒格瓦斯。这是从草原进入"另一种文明"的仪式感 |
| 2 | **格日勒阿妈奶茶馆** | 呼和浩特 | 锅茶 + 手把肉 + 酸奶饼 | 60-80 | Day 9，博物院看完之后的蒙餐犒赏。铜锅里煮着奶茶，手把肉蘸韭菜花酱，酸奶饼掰开冒着热气。这是你第一次真正"进入"内蒙古——不是在景区门口拍照，是用舌头 |
| 3 | **老厨家** | 哈尔滨（友谊路总店） | 锅包肉 | 60-80 | Day 27，6,180km之后。坐在锅包肉发源地的木头椅子上，外面的中央大街人来人往，你夹起一块外酥里嫩的锅包肉——醋香扑鼻。这是旅程的句号 |
| 4 | **凤临阁** | 大同古城 | 百花烧麦 | 80-120 | Day 10，你刚看完云冈石窟和应县木塔，脑子里全是北魏和辽代。走进一个雕梁画栋像宫殿的饭店，一笼百花烧麦端上来——面皮薄到透光，馅料从褶子里透出颜色。古建之旅要有配得上的晚餐 |
| 5 | **列娜餐厅** | 黑河 | 红菜汤 + 罐焖牛肉 + 俄式烤鱼 | 80-120 | Day 25，你在黑龙江畔，对岸750米就是俄罗斯。窗外江风吹着，桌上摆着红菜汤和黑列巴。老板娘是对岸过来的俄罗斯族，你和她聊天——这顿饭吃的是边境，不只是俄餐 |

## 📱 旅途实用提示

| 事项 | 说明 |
|------|------|
| **离线地图** | 出发前下载：甘肃+宁夏+山西（大同）+河北（张家口）+内蒙古全境+黑龙江全境 |
| **加油站** | 进入大兴安岭后见加油站就加满，不要等油表报警 |
| **防火** | 大兴安岭林区全年防火，打火机在检查站会被收走 |
| **边境** | 黑河黑龙江边禁止无人机飞行，江面中心线即国界 |
| **蚊虫** | 黑龙江边+草原蚊虫史诗级凶猛，防蚊面罩比驱蚊液管用 |
| **信号** | 根河→加格达奇林区段无手机信号，离线地图提前下载 |
| **保暖** | 阿尔山8月底夜间5-8°C，轻薄羽绒内胆放尾包随时取用 |
| **支付** | 沿途所有地方微信/支付宝全覆盖，带少量现金（200元以内）备用即可 |
| **语言** | 全程普通话无障碍。内蒙牧区部分老牧民只说蒙语，但年轻人和商家都会汉语 |
| **住宿预订** | 东乌旗、根河、嫩江等小地方建议提前1-2天电话确认。大城市当天订即可 |
| **拍摄时间** | 草原/湿地/林区——清晨和傍晚光线最好。中午光线平，适合赶路 |
| **高德vs百度** | 两个都装。高德在北方国道导航更准确，百度在城市内更好用 |
